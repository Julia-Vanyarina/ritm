# Ритм — инструкция по установке и подключению

«Ритм» — личное приложение для iPhone: еда с калориями и БЖУ, вода, вес и замеры, тренировки.

**Где что лежит**

| Где | Что | Кто видит |
|---|---|---|
| GitHub (репозиторий `ritm`) | только код приложения | кто угодно, но там нет ничего личного |
| iPhone | все ваши записи | только вы (плюс PIN-код) |
| Яндекс Диск, папка `Приложения/Ритм` или `Ритм` | резервная копия (по желанию с паролем) | только вы |
| Ноутбук, `ritm.db` | база для DBeaver | только вы |

**Что в архиве**

- `index.html`, `sw.js`, `manifest.webmanifest`, папка `icons` — само приложение, это идёт в GitHub
- папка `laptop` — скрипт для ноутбука, в GitHub **не загружать**

---

## Шаг 1. Выложить приложение (на ноутбуке, 5 минут, один раз)

1. Откройте **github.com** → кнопка **New** (новый репозиторий).
2. Repository name: `ritm`. Видимость: **Public**. Бесплатный хостинг GitHub Pages работает только с публичными репозиториями, но там будет лежать только код, без ваших записей.
3. **Create repository** → ссылка **uploading an existing file**.
4. Перетащите в окно `index.html`, `sw.js`, `manifest.webmanifest` и папку `icons` целиком. Нажмите **Commit changes**.
5. В репозитории: **Settings → Pages**. В разделе Branch выберите **main** и **/ (root)** → **Save**.
6. Подождите 1–2 минуты и обновите страницу. Сверху появится адрес вида
   `https://ВАШ-ЛОГИН.github.io/ritm/` — это адрес приложения.

## Шаг 2. Поставить на iPhone (2 минуты)

1. Откройте адрес приложения **в Safari** (именно в Safari, не в Яндекс Браузере и не в Chrome).
2. Кнопка «Поделиться» (квадрат со стрелкой) → **На экран «Домой»** → **Добавить**.
3. Дальше открывайте «Ритм» только с этого значка. Интернет ему нужен лишь для поиска продуктов и сканера штрихкодов.

⚠️ Если удалить значок с экрана, записи на телефоне удалятся вместе с ним. Поэтому шаг 4 важен.

## Шаг 3. Первая настройка в приложении

1. Вкладка **Ещё** → «Мои данные и норма»: возраст, рост, вес, активность, цель. Появится норма калорий и БЖУ.
2. Там же **PIN-код** и цвет оформления.
3. Вкладка **Еда** → «+ Добавить»: поиск по базе, сканер штрихкода (кнопка ▥) или своё блюдо вручную. Отметьте «В избранное», и блюдо станет кнопкой в один тап.

### Что ещё есть в приложении

- **Рецепты.** «+ Добавить» → «Рецепт из нескольких продуктов» (или Ещё → Мои рецепты). Добавьте ингредиенты в сыром виде с граммами. По желанию укажите вес готового блюда и число порций: калории и БЖУ на 100 г и на порцию посчитаются сами. При добавлении рецепта в дневник появятся кнопки «½ / 1 / 2 порции».
- **План тренировок.** Ещё → Тренировки: план: цель «N занятий в неделю» и расписание (день, занятие, время). Во вкладке «Спорт» видно, как идёт неделя. В день занятия появляется кнопка «Сегодня по плану… Отметить ✓».
- **Напоминания о занятиях.** Там же «📅 Добавить в календарь iPhone»: занятия попадут в обычный Календарь с напоминанием за час. Если после нажатия ничего не открылось, откройте «Ритм» по ссылке в Safari (не с иконки) и нажмите кнопку там. Поменяли расписание — удалите старые события в Календаре и добавьте заново.
- **Самочувствие.** На экране «Еда»: сон, энергия, настроение, заметка к дню. Отметку цикла включите в «Ещё → Самочувствие»: дни месячных подсветятся на графике веса.
- **Повтор дня.** Если сегодня пусто, можно повторить весь вчерашний день. А из любого прошлого дня — «Скопировать этот день в сегодня».
- **Итоги месяца.** Вкладка «Итоги»: средние калории и БЖУ, вес в начале и конце месяца, тренировки, выполнение плана, сон и настроение, заметки.
- **Тёмная тема.** Ещё → Оформление: «Как в iPhone», «Светлая» или «Тёмная».

## Шаг 4. Резервная копия на Яндекс Диск

На ноутбуке должна стоять программа **Яндекс Диск** для Windows, чтобы копия сама появлялась на компьютере. Если её нет, скачайте с disk.yandex.ru.

По желанию в «Ритме» → **Ещё → Резервная копия** можно задать **пароль шифрования**. **Запишите его**: восстановить пароль невозможно, без него не откроется ни копия, ни база на ноутбуке.

Есть два способа сохранять копию. Первый настраивается один раз (минут 10), а потом это два нажатия. Второй работает без настройки, но дольше.

### Способ А. Команда «В Яндекс Диск» (быстрый)

**1. Получить ключ доступа к Диску (на ноутбуке, один раз)**

1. Откройте **oauth.yandex.ru** под своим аккаунтом → **Создать приложение** (или «Зарегистрировать новое приложение»).
2. Название: `Ритм`. Платформа: **Веб-сервисы**.
3. Redirect URI: нажмите **«Подставить URL для отладки»** (появится `https://oauth.yandex.ru/verification_code`).
4. Доступы: **Яндекс Диск REST API → «Доступ к папке приложения на Диске»**. Больше ничего не отмечайте: ключ будет работать только с одной папкой, остальной Диск он не увидит.
5. Сохраните и скопируйте **ClientID**.
6. Откройте в браузере адрес, подставив свой ClientID вместо слов в конце:
   `https://oauth.yandex.ru/authorize?response_type=token&client_id=ВАШ_CLIENTID`
7. Разрешите доступ. Яндекс покажет **токен**, длинную строку, начинается обычно с `y0_`. Отправьте её себе на телефон (например, в «Избранное» в мессенджере). Токен действует год, потом пункты 6–7 нужно повторить.

**2. Собрать команду на iPhone (один раз)**

Откройте стандартное приложение **«Команды»** → «+» (новая команда) → назовите её `В Яндекс Диск`. Добавьте действия по порядку (поиск действий — строка внизу):

1. **«Получить содержимое URL»**
   - URL: `https://cloud-api.yandex.net/v1/disk/resources/upload?path=app:/ritm-backup.json&overwrite=true`
   - Раскройте стрелку «Показать больше» → Метод: **GET** → Заголовки → «Добавить новый заголовок»: ключ `Authorization`, значение `OAuth ВАШ_ТОКЕН` (слово OAuth, пробел, токен).
2. **«Получить значение словаря»** → ключ: `href`, словарь: «Содержимое URL».
3. **«Получить содержимое URL»** (ещё раз)
   - URL: нажмите и выберите переменную **«Значение словаря»**.
   - Метод: **PUT** → Текст запроса: **Файл** → Файл: переменная **«Ввод команды»**.
4. **«Показать уведомление»** → текст `Копия Ритма на Диске ✓`.

Затем нажмите на название команды вверху → **«Подробнее»** (значок ⓘ) → включите **«Показывать в меню „Поделиться“»** → в типах ввода оставьте только **Файлы**.

**3. Сохранять копию (раз в неделю)**

«Ритм» → **Ещё → Сохранить копию** (или нажмите на напоминание на главном экране) → в меню внизу выберите **«В Яндекс Диск»**. Готово: файл ляжет на Диск в папку **Приложения → Ритм**. В первый раз iPhone может спросить разрешение на доступ к cloud-api.yandex.net, нажмите «Разрешать всегда».

### Способ Б. Через «Файлы» (без настройки)

Яндекс Диск в «Файлах» на iPhone открыт только для чтения, поэтому в два приёма:

1. «Ритм» → **Ещё → Сохранить копию** → «Сохранить в Файлы» → **На iPhone** → «Сохранить» (на вопрос о замене — «Заменить»).
2. Приложение **Яндекс Диск** → папка `Ритм` → «+» → «Загрузить файл» → На iPhone → `ritm-backup.json`.

### Как восстановить (новый телефон, случайно удалили значок)

Поставьте приложение (шаг 2). Скачайте `ritm-backup.json` в приложении Яндекс Диск на телефон: файл → «•••» → «Сохранить в Файлы» → На iPhone. Затем «Ритм» → **Ещё → Восстановить из копии** → На iPhone → `ritm-backup.json`. Если копия с паролем, приложение его спросит.

## Шаг 5. Данные в DBeaver на ноутбуке

**Подготовка (один раз):**

1. Скопируйте папку `laptop` из архива куда удобно, например в `Документы\Ритм`.
2. Если ставили пароль шифрования: откройте командную строку (Win+R → `cmd` → Enter) и выполните
   `py -m pip install cryptography`
3. Сохраните копию на телефоне (шаг 4) и дважды щёлкните **«Обновить базу.bat»**. Рядом появится файл `ritm.db`.
4. В DBeaver: **База данных → Новое соединение → SQLite → Далее**. В поле «Путь» выберите этот `ritm.db` → **Готово**. Если DBeaver предложит скачать драйвер, соглашайтесь.

**Каждый раз, когда хотите свежие данные:**

1. Сохраните копию на телефоне (шаг 4) и подождите, пока Яндекс Диск синхронизируется на ноутбуке.
2. Дважды щёлкните **«Обновить базу.bat»**. Скрипт сам найдёт копию в папке Яндекс Диска, спросит пароль (если он есть) и обновит `ritm.db`.
3. В DBeaver выделите соединение и нажмите **F5**.

Скрипт заодно откладывает каждую копию в папку `архив` с датой, так что на ноутбуке копится история.

**Что в базе:**

| Таблица | Что в ней |
|---|---|
| `food` | каждая запись еды: дата, приём пищи, название, граммы, ккал, БЖУ |
| `daily_totals` | итоги по дням: ккал, БЖУ, вода, минуты тренировок, сон, энергия, настроение |
| `weight` | взвешивания и замеры |
| `weekly_weight` | средний вес по неделям |
| `workouts` | тренировки: вид, минуты, ощущения 1–5, заметка |
| `days` | самочувствие по дням: сон, энергия и настроение 1–5, месячные, заметка |
| `recipe_items` | состав ваших рецептов |
| `plan` | расписание тренировок |
| `water`, `products`, `profile`, `info` | вода, ваши продукты, данные для нормы, когда собрана база |

Например: `SELECT * FROM daily_totals ORDER BY date DESC LIMIT 14;`

База нужна для просмотра и анализа. Правки в DBeaver на телефон не попадут, а при следующем запуске скрипта база пересоберётся из свежей копии.

## Если что-то не так

- **Скрипт пишет «Не нашла ritm-backup.json».** Проверьте, что программа Яндекс Диск на ноутбуке запущена и файл уже скачался. Или просто перетащите `ritm-backup.json` мышкой на «Обновить базу.bat».
- **Команда «В Яндекс Диск» пишет об ошибке 401.** Токен истёк или скопирован не полностью. Получите новый (шаг 4, способ А, пункты 6–7) и вставьте в заголовок `Authorization` после слова `OAuth` и пробела.
- **Команды нет в меню «Поделиться».** Проверьте в её настройках «Показывать в меню „Поделиться“» и тип ввода «Файлы». Если её всё равно не видно, пролистайте ряд действий вниз, команды обычно в самом конце.
- **На Диске появился `ritm-backup 2.json`.** Значит, при сохранении не нажали «Заменить». Ничего страшного: скрипт берёт самый свежий файл. Лишние копии можно удалить.
- **`py` не найден.** Попробуйте `python` вместо `py` в командной строке и в файле `Обновить базу.bat` (открыть его можно Блокнотом).

## Как обновлять приложение

Загрузите новые `index.html` и `sw.js` в репозиторий `ritm` поверх старых (Add file → Upload files → Commit changes). При следующем запуске с интернетом телефон подтянет обновление. Если не подтянулось сразу, закройте «Ритм» свайпом и откройте снова. Записи при этом сохраняются. Если правите `index.html` сами, увеличьте номер версии в `sw.js` (`ritm-v2` → `ritm-v3`).

## О базе продуктов

Поиск и сканер берут данные из открытой базы Open Food Facts. Магазинных продуктов со штрихкодами в ней много, а домашней еды и блюд из кафе мало. Такие блюда удобно один раз внести вручную и добавить в избранное.

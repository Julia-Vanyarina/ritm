# Ритм — инструкция по установке и подключению

«Ритм» — личное приложение для iPhone: еда с калориями и БЖУ, вода, вес и замеры, тренировки.

**Где что лежит**

| Где | Что | Кто видит |
|---|---|---|
| GitHub (репозиторий `ritm`) | только код приложения | кто угодно, но там нет ничего личного |
| iPhone | все ваши записи | только вы (плюс PIN-код) |
| Яндекс Диск, папка `Ритм` | резервная копия (по желанию с паролем) | только вы |
| Ноутбук, `ritm.db` | база для DBeaver | только вы |

**Что в архиве**

- `index.html`, `sw.js`, `manifest.webmanifest`, папка `icons` — само приложение, это идёт в GitHub
- папка `laptop` — скрипт для ноутбука, в GitHub **не загружать**

---

## Шаг 1. Выложить приложение (на ноутбуке, 5 минут, один раз)

1. Откройте **github.com** → кнопка **New** (новый репозиторий).
2. Repository name: `ritm`. Видимость: **Public**. Бесплатный хостинг GitHub Pages работает только с публичными репозиториями, но там будет лежать только код, без ваших записей.
3. **Create repository** → ссылка **uploading an existing file**.
4. Перетащите в окно `index.html`, `sw.js`, `manifest.webmanifest` и папку `icons` целиком. Нажмите **Commit changes**.
5. В репозитории: **Settings → Pages**. В разделе Branch выберите **main** и **/ (root)** → **Save**.
6. Подождите 1–2 минуты и обновите страницу. Сверху появится адрес вида
   `https://ВАШ-ЛОГИН.github.io/ritm/` — это адрес приложения.

## Шаг 2. Поставить на iPhone (2 минуты)

1. Откройте адрес приложения **в Safari** (именно в Safari, не в Яндекс Браузере и не в Chrome).
2. Кнопка «Поделиться» (квадрат со стрелкой) → **На экран «Домой»** → **Добавить**.
3. Дальше открывайте «Ритм» только с этого значка. Интернет ему нужен лишь для поиска продуктов и сканера штрихкодов.

⚠️ Если удалить значок с экрана, записи на телефоне удалятся вместе с ним. Поэтому шаг 4 важен.

## Шаг 3. Первая настройка в приложении

1. Вкладка **Ещё** → «Мои данные и норма»: возраст, рост, вес, активность, цель. Появится норма калорий и БЖУ.
2. Там же **PIN-код** и цвет оформления.
3. Вкладка **Еда** → «+ Добавить»: поиск по базе, сканер штрихкода (кнопка ▥) или своё блюдо вручную. Отметьте «В избранное», и блюдо станет кнопкой в один тап.

## Шаг 4. Резервная копия на Яндекс Диск

**Подготовка (один раз):**

1. Установите на iPhone приложение **Яндекс Диск** из App Store и войдите в аккаунт.
2. Откройте приложение **Файлы** (стандартное на iPhone) → **Обзор** → «•••» вверху → **Изменить** → включите **Яндекс Диск** → Готово.
3. На ноутбуке должна стоять программа **Яндекс Диск** для Windows, чтобы файлы с Диска сами появлялись в папке на компьютере. Если её нет, скачайте с disk.yandex.ru.
4. По желанию: в «Ритме» → **Ещё → Резервная копия** задайте **пароль шифрования**. Тогда копию нельзя будет прочитать без пароля. **Запишите пароль**: восстановить его невозможно, и без него не откроется ни копия, ни база на ноутбуке.

**Как сохранять копию (раз в неделю):**

1. «Ритм» → **Ещё → Сохранить копию** (или нажмите на напоминание на главном экране).
2. В меню iPhone выберите **«Сохранить в Файлы»**.
3. **Яндекс Диск** → в первый раз создайте папку `Ритм` (значок папки с плюсом) и откройте её → **Сохранить**.
4. Если iPhone спросит, заменить ли существующий файл, нажмите **Заменить**.

Со второго раза iPhone сам откроет последнюю папку, и останется нажать «Сохранить». Если копии нет больше недели, на главном экране «Ритма» появится напоминание. По нему можно сразу сохранить копию.

**Как восстановить** (новый телефон, случайно удалили значок):
поставить приложение (шаг 2) → **Ещё → Восстановить из копии** → Обзор → Яндекс Диск → `Ритм` → `ritm-backup.json`. Если копия с паролем, приложение его спросит.

## Шаг 5. Данные в DBeaver на ноутбуке

**Подготовка (один раз):**

1. Скопируйте папку `laptop` из архива куда удобно, например в `Документы\Ритм`.
2. Если ставили пароль шифрования: откройте командную строку (Win+R → `cmd` → Enter) и выполните
   `py -m pip install cryptography`
3. Сохраните копию на телефоне (шаг 4) и дважды щёлкните **«Обновить базу.bat»**. Рядом появится файл `ritm.db`.
4. В DBeaver: **База данных → Новое соединение → SQLite → Далее**. В поле «Путь» выберите этот `ritm.db` → **Готово**. Если DBeaver предложит скачать драйвер, соглашайтесь.

**Каждый раз, когда хотите свежие данные:**

1. Сохраните копию на телефоне (шаг 4) и подождите, пока Яндекс Диск синхронизируется на ноутбуке.
2. Дважды щёлкните **«Обновить базу.bat»**. Скрипт сам найдёт копию в папке Яндекс Диска, спросит пароль (если он есть) и обновит `ritm.db`.
3. В DBeaver выделите соединение и нажмите **F5**.

Скрипт заодно откладывает каждую копию в папку `архив` с датой, так что на ноутбуке копится история.

**Что в базе:**

| Таблица | Что в ней |
|---|---|
| `food` | каждая запись еды: дата, приём пищи, название, граммы, ккал, БЖУ |
| `daily_totals` | итоги по дням: ккал, БЖУ, вода, минуты тренировок |
| `weight` | взвешивания и замеры |
| `weekly_weight` | средний вес по неделям |
| `workouts` | тренировки: вид, минуты, самочувствие 1–5, заметка |
| `water`, `products`, `profile`, `info` | вода, ваши продукты, данные для нормы, когда собрана база |

Например: `SELECT * FROM daily_totals ORDER BY date DESC LIMIT 14;`

База нужна для просмотра и анализа. Правки в DBeaver на телефон не попадут, а при следующем запуске скрипта база пересоберётся из свежей копии.

## Если что-то не так

- **Скрипт пишет «Не нашла ritm-backup.json».** Проверьте, что программа Яндекс Диск на ноутбуке запущена и файл уже скачался. Или просто перетащите `ritm-backup.json` мышкой на «Обновить базу.bat».
- **В меню iPhone нет Яндекс Диска.** Повторите пункт 2 подготовки в шаге 4 (включить Яндекс Диск в приложении «Файлы»).
- **На Диске появился `ritm-backup 2.json`.** Значит, при сохранении не нажали «Заменить». Ничего страшного: скрипт берёт самый свежий файл. Лишние копии можно удалить.
- **`py` не найден.** Попробуйте `python` вместо `py` в командной строке и в файле `Обновить базу.bat` (открыть его можно Блокнотом).

## Как обновлять приложение

Загрузите новый `index.html` в репозиторий `ritm` поверх старого, а в `sw.js` увеличьте номер версии (`ritm-v1` → `ritm-v2`). При следующем запуске с интернетом телефон подтянет обновление, записи сохранятся.

## О базе продуктов

Поиск и сканер берут данные из открытой базы Open Food Facts. Магазинных продуктов со штрихкодами в ней много, а домашней еды и блюд из кафе мало. Такие блюда удобно один раз внести вручную и добавить в избранное.
